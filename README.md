# Portfólio de QA - Testes Funcionais em E-Commerce

Este repositório contém a documentação de garantia de qualidade, análise de requisitos e cenários de testes para uma plataforma de E-Commerce.

## 🎯 Objetivo
Garantir a qualidade funcional, a usabilidade (UX) e a integridade das regras de negócio do fluxo de compras da plataforma.

## 🛠️ Conteúdo do Repositório
- **Plano de Testes e BDD:** Estratégia e cenários escritos em Gherkin (`casos-de-teste.md`).
- **Relatório de Bugs:** Documentação técnica de falhas encontradas (`relatorio-de-bugs.md`).

## 🚀 Competências Aplicadas
- Testes Funcionais e Exploratórios
- Análise de Requisitos e Regras de Negócio
- BDD (Behavior-Driven Development)
- Reporte e Ciclo de Vida de Bugs (Defect Lifecycle)
